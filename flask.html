Flask

Минималистичный микрофреймворк.

Описание

Flask — лёгкий микрофреймворк для Python, который даёт полную свободу архитектуры.

Установка

pip install flask

Примеры использования


from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello Flask"
