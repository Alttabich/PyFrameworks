Django

Мощный backend-фреймворк для создания масштабируемых веб-приложений.

Описание

Django — это высокоуровневый Python-фреймворк, который позволяет быстро создавать безопасные и масштабируемые веб-приложения. Он следует принципу “batteries included”, предоставляя множество встроенных инструментов.

Установка

pip install django

После установки можно создать проект:

django-admin startproject myproject

Примеры использования

Простой пример создания view в Django:


from django.http import HttpResponse

def home(request):
    return HttpResponse("Hello, Django!")

URL маршрутизация:


from django.urls import path
from . import views

urlpatterns = [
    path("", views.home),
]

Минусы

Django лучше всего подходит для больших проектов: интернет-магазинов, CRM-систем, новостных сайтов и корпоративных платформ.
