FastAPI

Современный async-фреймворк для создания API.

Описание

FastAPI — это современный Python-фреймворк для создания API с высокой производительностью. Основан на Starlette и Pydantic.

Установка

pip install fastapi uvicorn

Запуск сервера:

uvicorn main:app --reload

Примеры использования

Простой API:


from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello FastAPI"}
