Litestar

Современный async backend нового поколения.

Описание

Litestar — современный async-фреймворк с высокой производительностью и строгой архитектурой.

Установка

pip install litestar

Примеры использования


	from litestar import Litestar, get

	@get("/")
	def index() -> str:
		return "Hello Litestar"

	app = Litestar(route_handlers=[index])
